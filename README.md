# Dino Rush

A single-player endless runner with ten collectible dinos and five maps: Forest, Desert, Jungle, Rural, and Snow Mountain, using the supplied sprite sets. Requires Unity **6000.4.1f1** and the packages already listed in this project.

## Play

Open **Assets/Scenes/ForestRun.unity** (or **Dino Rush → Open Forest Run**) and enter Play mode. In the main menu, click **Play → Endless Mode**, choose a map preview, then click **Continue**. **Story Mode** is a disabled "Coming soon" placeholder. The selected map opens with an idle dino and **TAP TO START**. Tap/click anywhere in the game window (including portrait borders), or press Space/Enter, to begin running. ForestRun is also the first scene in Build Settings; all five maps use this shared scene. The original SampleScene and supplied artwork are left intact.

| Action | Controls |
| --- | --- |
| Choose mode / map | Play, Space, or Enter opens the mode submenu; Endless Mode opens the map selector; choose a card, then Continue |
| Start the prepared run | Tap/click anywhere, Space, Enter, Up, or W; the starting press does not also jump |
| Cancel before starting | Esc or P returns to the main menu, keeping the chosen map/dino |
| Retry | Space, Enter, click/tap the playfield, or Run Again |
| Jump | Space, Up, W, or click/tap the playfield |
| Double jump | Press a jump key or click/tap again while airborne; landing restores both jumps |
| Duck / fast drop | Hold Down or S; on touch, swipe downward on the playfield and keep holding, then release to stand; a brief duck in midair drops quickly |
| Pause / resume | Esc, P, or the pause button |
| Restart / leave run | Pause menu: Restart or Quit to Menu |
| Mute sound cues | M or SFX |

Jump over rocks, stumps, and crates, but **duck beneath low thorn branches**. Each run starts with **three hearts**, shown in the top-left corner instead of the former map/level panel. An obstacle hit removes one heart; the run ends only when all three are gone. A **0.55-second grace period** (previously 1.2 seconds) protects against overlapping pieces without skipping as much of the next sequence, and the same obstacle cannot damage you twice. Hits flash the selected dino's supplied white silhouette and crying pose, with a floating **−1 + heart** above it. Hit obstacles do not count as cleared. Pause freezes damage feedback and grace time; Retry/Restart restores all three hearts and clears the effects. Your distance is your score; speed gradually increases to a cap. Each dino can **double jump**: a fresh press/tap in midair gives one more upward boost, with no third airborne jump. Landing or restarting restores both jumps; holding a key does not automatically use the second jump. The small pre-landing input buffer is retained. Duck/fast-drop blocks jumping until landing, and air jumps do not emit ground dirt. Ground obstacles remain clearable with a single jump. Ducking is the safe route beneath a low branch, while a sufficiently high, well-timed jump can also pass above its visible body; there is no invisible wall above it. Switching away from the game automatically pauses it.

The trail advances through **six designed stages** at 0, 12, 28, 48, 75, and 105 seconds of active running:

| Stage | Focus |
| --- | --- |
| First Steps | Three small, spaced introductory hurdles, then double clusters |
| Long Leaps | Wider two-obstacle jumps |
| Low Canopy | Learn to duck beneath hanging thorn branches, mixed with ground clusters |
| Switchbacks | Jump → fast-drop → duck → jump, or duck → jump → fast-drop → duck |
| Burst Trail | Three-jump sequences with safe landing windows |
| Wild Run | Mixed skills at capped speed, with repeatable 30-second laps |

The first three hurdles remain approachable. Early stage changes open with a lighter recovery encounter, introduce the new signature, offer an easy practice jump, then repeat the signature; six-encounter sections subsequently build and release pressure. From Switchbacks onward, stage introductions shrink to a recovery encounter and one signature demonstration, followed by eight-encounter sections with five challenge encounters and one guaranteed recovery. Mixed jump/duck sequences and rapid multi-jump patterns are weighted more heavily, easy singles are rarer, and late recovery gaps are shorter. Teaching/recovery ground obstacles are smaller and teaching gaps more generous. Advanced patterns never appear before their teaching stage. Seeded artwork, size, group gaps, and recovery gaps keep sections varied, with repetition/rapid-streak limits. Every retry uses a fresh course.

Canopies unlock at 28 seconds with the **LOW CANOPY** stage banner, without revealing a Duck button or a HOLD DUCK prompt. Keyboard players hold Down/S; touch players swipe down on the playfield and keep holding, then release to stand. Touch taps jump on release so a downward swipe never accidentally spends a jump; mouse clicks retain immediate jumping. Pause, focus loss, menus, and restart release the gesture. From 48 seconds, three-obstacle switchbacks alternate ground hurdles and branches. A branch can follow a hurdle in **0.42–0.48 seconds** (measured between obstacle centers at the reserved arrival pace), encouraging an early fast drop after clearing the hurdle; duck-to-jump transitions retain **0.80–0.88 seconds**. Both sequence orders appear. The redesigned branch has a gnarled silhouette, layered bark shading and grain, a visible wood knot, moss, serrated leaf clusters, and five tapered amber thorns. Two thin, subtle decorative vines suspend it without a screen-height plank. Only the unchanged lower **0.8-world-unit branch band** is solid; the space above it is clear, and the lower collision edge is above the grounded crouched dino but below its standing head. It reuses the saved obstacle pool and runtime pixel artwork from `RunnerCanopyArt.cs` on all five maps. Egg routes around these encounters use recovery-gap pickups only, never a misleading jump arc into a branch.

Speed ramps continuously through **6.8 → 8.8 → 11.0 → 13.4 → 15.3 → 16.8** world units/second at the six stage boundaries. Wild Run stays capped at 16.8 (about 2.5× the starting pace). Jump physics, double jump, five starting hearts, one heart per hit, and inset ground hitboxes are unchanged; every encounter reserves a clean jump/duck/drop route.

A compact **stage name, progress bar, and countdown** sit between the hearts and score in landscape, or beneath the hearts in portrait; the retired top-left map/level panel remains hidden. A banner and sound celebrate each new stage. Wild Run counts laps indefinitely without raising the speed cap; each lap offers a brief recovery without resetting the encounter sequence to easy teaching jumps. Progress uses active simulation time: pause freezes it, resizing preserves it, and Restart starts at First Steps. Stage/lap banners take priority over nearby distance-milestone messages. The progress HUD hides on the title, tap-to-start, pause, and results screens to keep them focused.

`RunnerEncounterDirector.cs` uses its own seeded random stream, so dust effects cannot change the course. Encounters are spaced by distance rather than a fixed repeating timer. Cluster spans are limited by jump clearance, separate jumps reserve landing/recovery time at the predicted arrival pace, and combinations spawn atomically from the existing pool. Difficulty, upcoming spacing, and the course freeze while paused and reset on Restart. Tests simulate thousands of encounters and complete accelerating three-minute courses using the real jump/collision rules.

Duck uses the dino's crouched running frames and a shorter collision box. In midair it immediately cuts upward momentum and accelerates the descent until landing, even if you release early. Hold to remain crouched on landing; release to stand and jump again. Ducking cancels buffered jumps, so a fast drop never causes an accidental bounce. It does not let you pass through ground obstacles. Tap/click-to-jump and keyboard jump/duck remain available. The Jump button stays hidden; the existing **DUCK** hold button appears from Low Canopy onward on every screen size so touch players can respond to the new hazards. It hides on menus/pause/results and releases held input when hidden.

Your best score, sound preference, chosen dino, and last map are saved locally with PlayerPrefs. Restarting a run does not erase your best or change your dino/map.

UI buttons play a short, soft **click** on accepted activation, including Shop, map selection, Options, confirmations, and pause/results controls. Hover, cancelled presses, disabled buttons, and right-clicks are silent. The shared `RunnerUiButtonFeedback` binding avoids duplicate audio when UI effects are installed again, and its game-owned audio source lets closing-button clicks finish after the panel hides.

Slashes use dedicated, sample-based **Fire** (weighty flame ignition), **Lightning** (a sharp 0.75-second electric zap that carries through the slash, with a natural decay and no spell buildup), and **Water** (liquid splash/tail) effects instead of the earlier pitched-tone approximations. The short mono PCM files are in `Assets/Resources/Audio/Slashes`, where they can be auditioned in the Inspector; `SOURCES.txt` documents the CC0 sources, credits, and edits. `RunnerActionAudio.cs` loads them once per audio owner through Unity's shared asset cache; only UI clicks are synthesized there. A successful attack plays its equipped element once; blocked attacks never play a slash sound or spend an extra charge. Unlocking/equipping a different Shop style previews its sound once, while looping artwork stays silent. Slash sounds pause/resume with gameplay and stop on restart, results, or returning to the title. All sounds respect SFX mute and use separate UI/element sources so they do not interrupt egg pulls. Generated clips and sources are cleaned up with `RunnerAudio`; imported slash assets are retained for scene reloads and other owners. Neither loading nor playback consumes gameplay randomness.

### Collectible dinosaur eggs

Every map now offers optional **speckled egg trails**. Four safe starter eggs introduce collecting before the first obstacle. Low trails sit in clear recovery gaps (up to four eggs), riskier single-jump arcs offer six eggs around obstacles, and high arcs offer eight eggs along a double-jump route. High arcs only appear where there is room to land before the next encounter; rapid obstacle sequences keep their existing single-jump rhythm. Eggs never overlap obstacle hitboxes, and skipping a trail has no penalty. Collecting eggs does not alter obstacle scheduling, distance scoring, or health.

Touch an egg with the dino to collect it once. The original short pickup sound plays (respecting SFX mute), a gold burst marks the pickup, and a short floating **+1** confirms the award. The egg briefly pops, then curves into the **EGGS** counter with a soft glow and a five-glint comet trail. An expanding gold ring and a small squash/tilt of the counter icon complete the arrival. Eggs are credited immediately to both the run counter and your saved Shop balance, so interrupting the animation never loses a pickup. Flights follow the counter when the screen rotates or its safe area changes, hide and freeze during pause, and clear on results/restart or returning to the title. The counter adapts to portrait/safe areas, and the results card shows the run's total. World eggs and sparkles freeze during pause/game over, stay absent on menus and Tap to Start, and reset on retry/restart or returning to the title. Restarting, quitting a run, or reloading never clears the saved balance or credits the same run a second time.

### Shop and dino fragments

**Shop** replaces Customize. Spend **50 collected eggs** to hatch a mystery egg and receive **1–20 fragments (inclusive)** for one uniformly random **locked** dino. The amount is also random. **Blue** is available from the start; **Red, Yellow, Green, Cole, Kira, Kuro, Loki, Mono, and Sena** each unlock automatically at **100 of their own fragments**. Tap an owned card to equip it; locked cards cannot be selected, including through the gameplay API. Full rewards are retained when a purchase crosses 100. Already owned dinos never receive mystery-egg fragments; purchasing is disabled when your balance is too low or every dino is unlocked. Balance, fragments, unlocks, and selection persist locally with PlayerPrefs. Existing color IDs and progress are preserved when the roster grows. `RunnerShopProgress.cs` defines the price and fragment rules and uses its own random stream, independent of gameplay.

The redesigned Shop separates its **egg-hatching station** from a **paged collection**: four roomy cards per page, owned/total count, individual fragment bars, and Equipped/Locked/Tap to Equip badges. Previous/Next browse all ten dinos without spending currency or changing your selection. Closing a purchase reveal opens the rewarded dino's collection page. Landscape uses a two-column station/collection panel; portrait stacks the station and a 2×2 card grid with touch-sized paging controls. `RunnerShopCollection.cs` owns pagination and responsive card layout without recreating controls.

Every category highlights the saved balance in a compact dark **egg-wallet badge** with a gold accent, a small collectible egg icon, and comma-separated numbers. The badge uses 36-unit desktop / 44-unit phone heights and 16/18-point text rather than the earlier oversized indicator. Purchases refresh the exact balance immediately; long balances fit without truncation. `RunnerShopWallet.cs` shares the presentation across Dinos, Trails, and Slashes. **Dino Rush → Improve Shop Egg Wallets** saves the editable badges and shared currency-icon asset without rebuilding the rest of the menu.

Mystery pulls have dedicated **pull-start whooshes, shell percussion, rising hatch tones, fragment ticks, and musical reveal chimes**. New dino unlocks use a brighter four-note celebration; ten-pulls chime each staggered card with rising notes. All respect SFX mute, run independently of time scale, and use pre-generated clips without consuming gameplay randomness. Skip/Reveal All plays one result cue instead of stacking missed sounds, and closing the reveal stops its audio. `RunnerMysteryEggAudio.cs` owns synthesis; `RunnerAudio.cs` owns playback and clip/source cleanup. Tests cover stage timing, per-card cues, mute, skip, slow frames, waveform bounds, wallet limits, and layout. Optional captures: `shop-wallet-0` through `shop-wallet-2` and their `shop-wallet-portrait-*` variants.

Choose **Hatch 1 — 50 eggs** or **Hatch 10 — 500 eggs**. A ten-pull always delivers ten independent **1–20-fragment** rewards with the same rates as a single pull (no extra rarity or guaranteed unlock). Its eligible pool is the dinos locked **at purchase time**; duplicates stack and retain all excess fragments, even if a dino reaches 100 during that batch. Each newly unlocked dino is celebrated only once. This also guarantees ten complete rewards when only one locked dino remains. Both buttons disable when all dinos are owned; the ten-pull additionally requires at least 500 eggs. One charge and all ten rewards are saved before any animation starts.

`RunnerShopBatchPresentation.cs` plays the gacha-style ten-pull: **orbiting eggs gather → shells charge/crack → ten staggered hatch/card-flip reveals → full results grid**. Matching supplied egg art, warm rays, and highlighted **NEW DINO!** badges accompany each result. The final screen shows every dino/fragment reward and the total fragments/new unlocks. **Reveal All** or Esc/P skips directly to the complete grid; **Continue** or another Esc/P returns to the collection, focusing a rewarded/newly unlocked dino. The reveal uses unscaled time, respects SFX mute, blocks repeat purchases/underlying controls, and adapts from a 5×2 desktop grid to a 2×5 phone grid without rerolling or replaying rewards. All animation frames share the single-hatch cache and its cleanup. Optional captures: `shop-ten-pull-option`, `shop-ten-pull-summon`, `shop-ten-pull-hatching`, `shop-ten-pull-results`, and their phone variants.

The Shop features a framed **animated egg showcase**, glowing pixel glints, and a dedicated **Hatch Egg** purchase button. Buying opens a cinematic reward panel: the matching egg **wobbles → cracks → hatches**, then reveals the dino with a gold burst, a bouncing **+fragment count-up**, an animated fragment-progress bar, and a special heading when the dino unlocks. The original three eggs use `egg - 2`, `egg - 3`, and `egg- 4`; each named dino uses its own `dino/<name>/egg` move/crack/hatch strips. Fixed 24×24 runtime cells preserve alignment across all nine egg variants without modifying the original sprite slices or importers. The reveal runs on unscaled time, reflows for phones, and adds crack/reveal/counting sound cues respecting SFX mute.

The purchase is committed **once before the animation**, so interruption or scene exit cannot lose the reward or charge again. The modal blocks underlying Shop controls and repeated purchases. **Skip Reveal** (or Esc/P) finishes the single-pull count immediately; **Continue** returns to the Shop. Esc/P first skips, then dismisses the reward, and only then leaves the Shop. `RunnerShopPresentation.cs` owns presentation and cached-frame cleanup; `RunnerHatchGlowGraphic.cs` draws texture-free rays and pixel glints; `RunnerEggHatchCatalog.asset` stores original sheet bindings. **Dino Rush → Add Animated Mystery Egg Shop** authors both purchase buttons, the editable showcase, and both reward panels in place. Regular menu/dino/layout authoring also preserves these controls.

### Reset account

**Options → Reset Account** opens a separate, blocking confirmation with **Cancel** and **Reset**. Opening it, cancelling, or pressing Esc/P never changes progress. Confirming permanently clears all dino fragments/unlocks (Blue remains available), trail ownership/equipment, slash styles/equipment/charges, eggs, high score, daily-mission progress/claims, and the selected dino/map. The title returns with Blue and Forest selected; sound settings and unrelated PlayerPrefs remain untouched. This is a local account reset, not a cloud-account operation.

`RunnerAccountProgress.cs` lists the exact reset keys instead of using `PlayerPrefs.DeleteAll`. `ForestRunnerGame.ResetAccount` also clears live run/record state and the existing mission snapshot, so a later save, focus event, or scene reload cannot resurrect old progress. `RunnerAccountReset.cs` owns the responsive confirmation and rejects hidden, repeated, or non-menu reset events. **Dino Rush → Add Account Reset and Compact Shop Wallets** saves the editable UI without resetting any account data. Tests restore the previous profile after checking cancel/modal behavior, confirmation, repeat-event safety, persistence, retained sound settings, and phone/tablet layouts. Captures include `options-account-reset`, `reset-account-confirm`, their phone variants, and `reset-account-fresh-shop`.

### Trail effects Shop

The Shop has separate **DINOS**, **TRAILS**, and **SLASHES** categories. Trails have animated, free-to-view previews and cost **2,000 eggs each** from the same saved wallet as mystery eggs:

- **Wind:** small pale wind blades that curl, rotate, and float behind the dino.
- **Inferno:** warm fire embers that drift backward, rise, tumble, and fade.
- **Voltage:** small blue-white current sparks that drift, rotate, and flicker out.
- **Frost:** six-point ice crystals that tumble and drift gently downward.
- **Blossom:** soft pink petals that flutter and rotate on a turbulent breeze.
- **Cosmic:** bright stars that twinkle into violet stardust.

The six effects are split into two pages of three cards. A balance/currently-equipped header sits above larger, color-accented preview cards. Each card shows its price once, or a clear **OWNED / IN USE** badge, with a separate **BUY TRAIL / EQUIP / EQUIPPED** action. **PREV / NEXT** and a persistent page counter have their own row below the cards; Back and Remove Trail are separate footer actions. Paging never spends eggs or changes equipment, and hidden-page previews stop simulating. Both pages have stacked phone cards with larger labels, buttons, and live hopping dino previews. Prices and saved ownership are unchanged.

### Daily missions

The main menu's **MISSIONS** button opens three daily goals, with progress bars, an egg balance, individual **CLAIM** buttons, and a reset countdown:

| Goal (across matches, on any map) | Reward |
| --- | --- |
| Run 500 metres | 100 eggs |
| Collect 30 eggs during runs | 200 eggs |
| Clear 25 obstacles | 300 eggs |

All three goals are available each day for a total of **600 eggs**. Clearing means passing an obstacle without hitting it, or shattering it with a slash; paid attacks and unlocked dinos are never required. Distance and pickups count only during actual running, not menus, the start prompt, pause, or results. Claimed mission rewards do not count as egg pickups. Completion never automatically credits the wallet: claim each reward once, with the claim flag and wallet saved before feedback. Duplicate clicks/reloads cannot pay twice, and a full wallet leaves the reward available to claim after spending eggs.

Goals reset at **local midnight**, including during a run or while viewing Missions. Unclaimed rewards expire; missed days do not bank rewards. An offline local-date high-water mark prevents clock rollback from reopening previously claimed days; this is not server-verified anti-cheat. Progress survives matches and app restarts. Pickups/clears save immediately, distance checkpoints every five simulation seconds, and pause, focus loss, run resets, results, menu transitions, and orderly shutdown flush remaining progress. Existing wallet, dino, trail, and slash save keys are unchanged.

`RunnerDailyMissions.cs` owns the separate versioned JSON preference, goals, date rollover, and guarded claims. `RunnerDailyMissionsPanel.cs` presents the same shared game progress with responsive desktop/phone cards. **Dino Rush → Add Daily Missions** authors the editable button and page in place without rebuilding existing UI artwork. Permanent achievements are not part of this first version.

### Slash attacks

**SLASHES** previews the supplied twelve-frame **Fire, Lightning, and Water** animations. Each style costs **5,000 eggs** to unlock permanently; unlocking selects the style but does not give free attacks. Unlocked styles can be swapped freely and all have the same power. **+1 Charge** costs **1,000 eggs**, with a shared magazine of at most **3 charges**. Paid, unused charges persist through menus, retries, and app restarts; only firing consumes one, saved immediately. No automatic refills or retry refunds occur.

During a run, press **Enter / Numpad Enter**, or tap the **Slash indicator**, to fire forward at the dino's current height. Enter no longer jumps during gameplay; Space/Up/W and playfield taps still jump. A strike can shatter multiple ground obstacles or low canopies along its path, leaving texture-matched tumbling fragments. Distant or vertically missed targets remain dangerous. Attacks and debris freeze on pause and clear on retry, game over, or returning to the menu. The indicator shows remaining usable charges and the equipped style; at most **three attacks per match**, with no charge consumed for blocked or paused inputs. Shop controls cannot refill during a run.

**Dino Rush → Add Slash Attacks and Shop** saves the new editable UI, attack component, HUD binding, and `Assets/RunnerSlashCatalog.asset`. The catalog references the original PNG textures via common-canvas sprite subassets, avoiding size jumps from differently trimmed source sprites without changing their importers. Debris is pooled (at most 90 pieces), generated fragments are disposed on scene teardown, and attack visuals do not consume gameplay RNG. `RunnerSlashProgress.cs` owns the separate saved unlock/style/charge keys; existing dino/trail progress is untouched.

Buying permanently unlocks and immediately equips a trail. Owned trails can be equipped again for free; **No Trail** removes the effect without losing ownership. Only one trail is active at a time. Ownership and selection survive scene/app reloads; invalid/unowned selections safely show no trail. Insufficient funds and repeated purchase events cannot deduct eggs or grant an unowned cosmetic. Dino hatching and its existing prices/rewards are unchanged.

These are native Unity **world-space particles**, not baked trail sheets, a solid aura, or ghost-dino sprites. Only fresh particles spawn at the dino's current height; existing particles retain their own position, lifetime, velocity, and rotation. Jumps and landings therefore leave an airborne wake instead of carrying a flat picture around. Each effect uses its own small generated 64×64 particle texture and motion profile. Turbulence and independent velocities add drift; lifetime curves control size, color, and fading.

The particles render behind the dino, work with every dino/map, spawn lower when ducking, freeze while paused, fade after game over, and clear on retry/menu transitions. Each system is capped at 80 particles and uses its own cosmetic random seed. Movement, collisions, pickups, and gameplay randomness are unchanged. Runtime systems, materials, and generated textures are cleaned up with the scene. Shop previews use the same particle simulation and periodically hop the preview dino to demonstrate the airborne wake; phone layouts stack the cards. Saved ownership, equipped IDs, and the **2,000-egg price** are unchanged; Wind retains the former Smoke save key so existing owners keep it.

`RunnerTrailProgress.cs` owns prices, saved ownership, and equipment. `RunnerTrailShop.cs` owns category switching, purchases, previews, paging, and responsive layouts. `RunnerTrailParticles.cs` manages the native simulation; `RunnerTrailParticleArt.cs` creates individual particle textures; `RunnerTrailPreview.cs` and `RunnerPlayerTrail.cs` integrate it into UI/gameplay. **Dino Rush → Add Trail Effects Shop** authors the editable categories/cards in place; normal Shop authoring also retains them. Tests cover prices, duplicate/invalid purchases, ownership persistence, equip/remove, independent particle motion across jumps/landings, hatch-modal guards, all-map/dino compatibility, pause/retry cleanup, lifetime fading, and both pages' layouts. Optional captures include `trail-shop-new-effects`, `trail-shop-new-effects-portrait`, `trail-world-<smoke/fire/electric/frost/blossom/cosmic>`, and `trail-air-<smoke/fire/electric/frost/blossom/cosmic>`.

The gift is saved before a short **opening pixel present, golden sparkles, and +1,000 egg count-up** displaying **“Gift from Bibek Giri Productions.”** Skip/Continue or Escape first completes the animation, then returns to the entry form with the code retained for another redemption; Back returns to Options. ### Pickup effect implementation

Pickup bursts combine a brief cream-colored flash, a thin expanding gold halo, four twinkling stars, and four tumbling gold shards with staggered timing, gentle drag/gravity, and a smooth fade. Effects stay compact around the pickup so the dino and obstacles remain readable. The floating +1 fades near the dino rather than following the egg across the screen; the flight lifts directly toward the counter without looping in front of obstacles.

`RunnerEggTrail.cs` designs optional routes using its own seeded random stream. `RunnerEggCollectibles.cs` reuses 64 egg renderers and 72 sparkle renderers without changing gameplay randomness. `RunnerEggFlights.cs` reuses 24 non-interactive UI eggs, each with a glow, five glints, and a +1 label, plus one shared arrival ring. `RunnerEggPickupGraphic.cs` draws lights and glints without extra textures; objects are pooled and animations never block jump or menu input. `RunnerEggArt.cs` creates point-filtered egg/star/halo/shard artwork at runtime and disposes it on scene exit. The original synthesized pickup clip is reused and cleaned up with the scene; supplied art and saved scene objects are untouched.

Pickup tests cover staggered burst/shard animation, pop/+1/comet/arrival phases, counter bounds, pause/rotation/reset behavior, pool reuse under bursts, exact-once rewards, mute, and pickup-sound cleanup. ### Screen sizes and orientation

The display adapts automatically to resolution changes, desktop window resizing, portrait/landscape rotation, and phone safe areas (notches and home indicators). Landscape keeps the existing layout; portrait moves the readouts to the top and reflows map and dino choices into two columns. The Duck control reflows to the lower-left in portrait when unlocked; Jump stays on the playfield. Menus and scrims fit the usable area, and returning to landscape restores the authored layout without resetting the run.

The world always retains the complete original course width. Taller landscape ratios, including **16:10 and 4:3**, fill the usable screen with extra sky and soil instead of horizontal letterbox bars; HUD controls stay at the top/bottom edges. Portrait and ultrawide layouts retain a framed world view where necessary, without stretching or cropping. This preserves the same dino size relative to obstacles, reaction distance, jump timing, and difficulty. Heart-loss popups and menu thoughts follow the camera's actual viewport. No resolution is forced at startup; native-resolution/fullscreen behavior is retained, and desktop windows are resizable.

## Maps

### Editing map layers without Play mode

Choose **Dino Rush → Edit Map Layers** to open `Assets/Scenes/MapLayouts.unity`. Desert, Jungle, Rural, and Snow Mountain are saved, visible Hierarchy objects in this separate editor-only layout scene. They sit side by side, spaced apart so their layers do not overlap. Select a map root and click **Preview This Map** to frame it in Scene view and the preview camera. Forest remains directly editable in the original `ForestRun.unity` hierarchy; use **Dino Rush → Open Forest Run** to return to it and play the game.

Expand a map, select its named scenery layer, and press **W** to drag it vertically, or edit **Bottom / Position Y** and **Height** on its layer component. Each layer groups all scrolling copies, so they move together. **Height** scales artwork uniformly; **Position X** is also editable for stationary moons. The ground and soil are fixed gameplay-height references.

Click **Save Layout to Game** on any layer or its map root to save that map's framing to `MapCatalog.asset` and refresh its selector preview. The next run uses those saved positions. **Ctrl+S alone saves only the layout scene**, not the gameplay catalog. **Reload Saved Layout** explicitly restores catalog values if you want to discard pending preview positioning or have edited the catalog elsewhere. Position edits and catalog application support Undo. Reopening the layout scene never rebuilds or overwrites your work, and this scene is not part of the game build. The gameplay scene, source art, map speeds, and collision rules are unchanged.

**Play → Endless Mode → Choose Your Map → Continue → Tap to Start** offers five preview cards: **Forest**, **Desert**, **Jungle**, **Rural** (the riverside village), and **Snow Mountain**. Selecting a card highlights and remembers it but does not start gameplay. Continue loads the selected map and dino into a waiting state: the course stays still, no obstacles or running dirt spawn, and score/stage timers stay at zero until a fresh tap or keyboard start. The confirmation click cannot dismiss the prompt, and the starting tap cannot also jump. Only ambient leaves/motes/snow/rain and the dino's idle animation continue. Gameplay controls/readouts stay hidden until running. Map Back returns to mode selection; its Back button or Esc/P returns to the title without starting a run. Esc/P also cancels the waiting screen without losing your choices. Shop also shows the selected map, and the pause heading uses its name.
